## O que define o "nível de qualidade" desse reel

### Identidade visual (paleta)
- Azul marinho escuro (fundo/vestimenta) + branco (texto) + dourado/laranja (detalhes/logo)
- Transmite: confiança, tecnologia, prestígio, premium.

### Composição
- Apresentador **recortado** (sujeito isolado) sobre **cenário digital desenhado**
  (Monte Fuji, pagode, bandeiras BR/JP, elementos de dados — binários, circuitos)
- Simetria: pessoa no centro, elementos gráficos preenchendo as laterais.

### Tipografia / hierarquia
- Topo: logo + título em sans-serif robusta branca (com detalhe gradiente)
- Rodapé: selo dourado + serifada elegante ("BUSINESS CONNECTION 2026") → toque editorial/premium
- Hierarquia clara: logo > título > assinatura de evento.

### Motion graphics
- Elementos tech animados (binários, linhas de circuito, bandeiras com efeito pincelada)
- Sobreposições de dados reforçando o nicho (Dados/IA).

### Produção
- Iluminação frontal suave no sujeito + color grade premium
- Fusão limpa entre foto real e elementos digitais (design gráfico de alto nível).

## Tradução para a régua de qualidade (princípios)
1. **Sujeito isolado + cenário desenhado** (não só o vídeo cru) — requer máscara/segmentação.
2. **Color grade cinematográfico** (contraste, saturação, temperatura controlada, vignette sutil).
3. **Tipografia premium** com hierarquia (sans bold p/ impacto + serif p/ autoridade).
4. **Motion graphics de marca** (elementos animados, números, circuitos/dados).
5. **Paleta de marca consistente** em tudo (fundo, texto, overlays, CTA).
