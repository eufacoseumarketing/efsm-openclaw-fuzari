# Client Reporting Pack

Use this skill when the report is more than a quick update and needs packaging.

## Workflow
1. Build the executive summary first.
2. Add KPI interpretation and evidence.
3. Add recommended actions.
4. Choose the right final format.
5. Do a final QA pass for clarity and consistency.

## Good outputs
- executive summary + deck
- doc + spreadsheet appendix
- pdf report pack
- short client note + attached deck
