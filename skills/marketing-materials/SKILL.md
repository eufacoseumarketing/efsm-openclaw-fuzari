# Marketing Materials

Use this skill when the request is not just "write content," but "turn this into a presentable artifact."

## Scope

This skill covers:
- static visual materials
- one-pagers
- campaign concepts
- sales collateral
- proposal visuals
- report visuals
- simple landing page or artifact mockups
- design direction for marketing and sales deliverables

## Decision rule

Bias toward communication value over decorative flourish.

A material is good when it:
- supports a business objective
- matches its audience
- is easy to scan
- has clear hierarchy
- looks intentionally designed

## Workflow

1. Clarify the artifact type, audience, and desired action.
2. Decide the medium:
   - static page or image
   - deck
   - document
   - simple web artifact
3. Build a strong content hierarchy before styling details.
4. Apply a restrained visual system:
   - 1 dominant visual direction
   - 1-2 support colors
   - clear typography hierarchy
   - strong spacing and margins
5. Keep text concise and purposeful.
6. Check whether the output looks commercially usable, not merely artistic.

## Agency-specific defaults

Optimize for materials such as:
- lead magnets
- campaign mockups
- proposal covers and visuals
- client one-pagers
- service sheets
- report summary visuals
- simple landing page concepts
- internal strategy visuals

## Guardrails

- Do not over-index on abstract art unless the user explicitly wants it.
- Do not import third-party branding by default.
- Do not let aesthetics overpower message clarity.
- If a brand system exists, follow it.
- If no brand system exists, use a clean neutral one.
