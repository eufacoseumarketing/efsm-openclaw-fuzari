Use when the material should be interactive or browser-based: simple landing pages, campaign microsites, interactive report views, calculators, or web mockups.

## Principles
- start with the user journey, not the component library
- keep the artifact purposeful
- avoid trendy default AI aesthetics
- prioritize scannability, responsiveness, and clear calls to action

## Practical guidance
- use a simple stack unless complexity is justified
- define sections and interactions before coding
- keep layout and copy aligned to the funnel stage
- test the final artifact visually before shipping when practical
