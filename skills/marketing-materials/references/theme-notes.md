Use themes as support, not as the main goal.

## Rules
- choose a dominant color family and a restrained accent
- use a clear heading/body type pairing
- keep contrast high enough for real use
- prefer consistency across pages/slides/assets over novelty on each page
- if the user already has branding, that branding wins

## Default fallback
If there is no brand guidance, use a neutral professional system:
- dark text
- light background
- one dominant accent color
- one support accent
- readable sans or serif/sans pairing
