# Marketing material types

Use this reference to choose the right artifact shape.

## One-pager
Use when the goal is a compact sales or service summary.

## Proposal visual support
Use when a proposal needs covers, section visuals, diagrams, or layout reinforcement.

## Campaign concept board
Use when a campaign idea needs visual direction without full production polish.

## Landing page concept
Use when the artifact should show structure, flow, and conversion logic in browser form.

## Report visual summary
Use when numbers need to be turned into an executive-friendly visual layer.

## Selection rule
Choose the lightest artifact that still helps the user sell, explain, or decide.
