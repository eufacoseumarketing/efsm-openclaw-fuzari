# MCP Integration Planning

Use this skill for planning integration surfaces, not for everyday campaign execution.

## Use cases
- deciding how an external API should be exposed to agents
- planning tool boundaries and naming
- designing read-only vs write tools
- specifying pagination, filtering, and error patterns
- evaluating whether an integration should be broad or workflow-focused

## Core principles
- tool names should be discoverable
- outputs should be focused and structured
- errors should be actionable
- read/write boundaries should be obvious
- prefer practical workflows over protocol purity

## Fit for this operation
Use this when building the next layer of capability for the agency, especially around CRM, ads, reporting, or internal systems.
